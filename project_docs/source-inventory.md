# IntraMind CampusAI — Source Inventory

This is an institutional document that is accessible to the public.
The first case study for IntraMind CampusAI was identified and the sources were uncovered.

This is the first case study on information that is available to the public from Taylor's University Lakeside Campus.

The platform is designed to be university neutral. Taylor's
University is used as the first case study in the real world.

---

## 1. Data Governance and Usage Principles

The project will follow these principles:

-Only use public institutional information.
-Avoid visiting documents that need a student/staff ID.
-Do not circumvent access controls.
-Do not make raw institutional source files accessible on GitHub.repository.
-Record source URLs, metadata, NOT redistribute copyrighted source documents through GitHub.
-Refer and reference to the original institutional source where appropriate.
-Do not suggest that Taylor's University is responsible for or operates IntraMind CampusAI.
-Rights and permissions (copyright and licensing issues) before any
public deployment containing institutional source content.

# 3. Planned Ingestion Strategy

The planned ingestion pipeline is:

Public Institutional Sources
        ↓
Source Identification
        ↓
Manual / Permitted Acquisition
        ↓
Document or Webpage Extraction
        ↓
Text Cleaning
        ↓
Metadata Extraction
        ↓
Text Chunking
        ↓
Embeddings
        ↓
Vector Database

The project will not implement automated website crawling
without proper permission.

---

# 4. Metadata to Record

Each source or document should have metadata such as:

- Source ID
- Title
- Institution
- Campus
- Category
- Source type
- Original URL
- Date accessed
- Publication/update date, if available
- Document version, if available
- Section
- Page number, for PDFs
- Content status
- Usage/copyright notes
